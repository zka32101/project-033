## 2. ADMIN TRAINING PROGRAM STRUCTURE

### 2.1 Three-Tier Certification Framework

**TIER 1: Platform Basics (Required for all staff)**
- Duration: 4 hours
- Content: Platform architecture, user roles, navigation, basic troubleshooting
- Delivery: Live sessions (Sep 15, 20, 25, 30) + asynchronous video
- Target: 100% completion by Sep 30
- Certification: "Platform Competency"

**TIER 2: Role-Specific Expertise (By team)**
- Content Admins (10): Module management, metadata, video workflows
- Engineering Admins (15): System monitoring, API testing, database access, performance tuning
- Operations Admins (12): User management, permissions, reporting, incident response
- Specialist Admins (5): Analytics dashboards, compliance auditing, localization workflows
- Duration: 8-16 hours per role, Sep 30 - Oct 31
- Certification: "Role Specialist"
- Target: 95%+ completion by Oct 31

### 4.4 Change Resistance Management

**Potential Resistance Points**

| Concern | Risk Level | Likelihood | Response |
|---------|-----------|-----------|----------|
| Training too demanding (42 hours) | Medium | High | Flexible pacing, async options |
| Role uncertainty post-launch | High | Medium | Clear role definitions, mentorship |
| New systems create work bottlenecks | High | Medium | Parallel running period, process optimization |
| Skill gaps undermine confidence | Medium | High | Extra support, safety nets, escalation |
| Fear of system reliability | High | Medium | Redundancy, dry-runs, incident rehearsal |

**Response Strategy**:
1. **Early involvement** in change design (get feedback, build buy-in)
2. **Transparent communication** (why changes needed, what's changing)
3. **Support structures** (training, mentorship, resources)
4. **Quick wins** (early successes build confidence)
5. **Feedback loops** (listen, adjust, demonstrate responsiveness)
