## Part 1: Video Format & Technical Specifications

### 1.1 Video Formats & Delivery

**Primary Format** (for platform):
- **Resolution**: 1920 x 1080 (Full HD)
- **Frame Rate**: 29.97 fps (NTSC, standard for web)
- **Codec**: H.264
- **Container**: MP4 (.mp4)
- **Bitrate**: 5000 kbps (for streaming quality)
- **Color Space**: Rec.709
- **Aspect Ratio**: 16:9

**Secondary Format** (for mobile optimization):
- **Resolution**: 1280 x 720 (HD)
- **Frame Rate**: 29.97 fps
- **Codec**: H.264
- **Container**: MP4 (.mp4)
- **Bitrate**: 2500 kbps
- **Aspect Ratio**: 16:9

**WebM Format** (for web compatibility):
- **Resolution**: 1920 x 1080
- **Frame Rate**: 29.97 fps
- **Codec**: VP9
- **Container**: WebM (.webm)
- **Bitrate**: 4000 kbps

**Delivery Specifications**:
- [ ] All videos delivered in 3 formats (1080p MP4, 720p MP4, 1080p WebM)
- [ ] File names follow convention: `Phase6A_[ModuleName]_[Format].mp4`
- [ ] Separate master file retained (for future re-edits)
- [ ] All files tested for playback on iOS, Android, web

### 1.2 Audio Specifications

**Audio Format**:
- **Sample Rate**: 48 kHz
- **Bit Depth**: 24-bit
- **Codec**: AAC
- **Channels**: Stereo (2-channel)
- **Bitrate**: 256 kbps

**Audio Quality Standards**:
- Professional narration quality (no background noise)
- Clear, audible (no distortion)
- Normalized levels (-3dB peak)
- No audio dropouts or gaps
- Background music/effects: -6dB below narration

**Voiceover Recording**:
- Professional voice talent (native English speaker for primary recordings)
- High-quality microphone (minimum: Rode Wireless GO 2 or equivalent)
- Recording space: Quiet room, with acoustic treatment
- Sample rate: 48 kHz during recording
- Backup recording: All takes recorded as backup

**Audio Mixing**:
- Narration: Primary audio track
- Background music: Secondary track (optional, -10dB below narration)
- Sound effects: Tertiary track (optional, -12dB below narration)
- All tracks properly balanced and panned

### 1.3 Subtitle & Captions

**Subtitle File Format**:
- Format: SRT (SubRip Text)
- Encoding: UTF-8
- Timing: Synced within 100ms of actual audio

**Subtitle Requirements**:
- [ ] Complete, word-for-word transcription
- [ ] Proper capitalization and punctuation
- [ ] Timing for all spoken content
- [ ] Font specifications for display:
  - Font: Arial or Verdana
  - Size: 18pt minimum
  - Color: White with black outline (for readability)

**Subtitle Placement**:
- Bottom of video: 20-30px from bottom
- Maximum 2 lines per subtitle
- Maximum 42 characters per line
- Avoid covering important on-screen elements

**Subtitle Delivery**:
- [ ] English SRT file (all videos)
- [ ] Timing file provided for translation team
- [ ] File naming: `Phase6A_[ModuleName]_[Language].srt`

### 1.4 Color Grading & Look

**Color Grading Standards**:
- Consistent look across all 18 videos
- Color temperature: Neutral (6500K daylight)
- Saturation: Moderate (+5-10% from neutral)
- Contrast: Standard video contrast (no extreme crushing)
- Shadows: Lifted to ~20% gray (readable)
- Highlights: Maintained with slight rolloff

**Reference Look**:
- Similar to professional e-learning platforms (Linkedin Learning, MasterClass)
- Professional but warm
- Enhanced but not oversaturated

**Color Grade Testing**:
- Export first video fully graded
- Review on Mac (standard sRGB), Windows (standard RGB), Mobile (iPhone/Android)
- Ensure consistency across devices
- Apply same LUT/grade to all 18 videos

### 2.2 Production (Week 3-5)

- Record without background music/effects (add in post)

## Part 3: Video Templates & Standards

### 3.1 Intro/Outro Standard

**Intro Sequence** (3 seconds for all videos):
- Safy logo appears with sound (0:00-0:03)
- Fade to black
- Module name appears as text (0:02-0:03)

**Intro Specs**:
- Duration: Exactly 3 seconds
- Logo: Safy HD logo file (provided)
- Sound: 1-second signature sound effect
- Text: Module name, white text, 48pt font
- Background: Solid black or subtle gradient

**Outro Sequence** (3 seconds for all videos):
- Fade to black (0:02 before end)
- Outro slide appears:
  - "Thank you"
  - "Learn more at [safy-url]"
  - Safy branding
- Duration: Exactly 3 seconds
- Sound: Optional soft music/sound effect

**Standard Template Delivery**:
- [ ] Intro/Outro template provided by Video Producer
- [ ] Template applied consistently to all videos
- [ ] Timing verified for accuracy

### 3.2 Title Card & Lower Thirds

**Title Card Format** (if used as scene opener):
- Duration: 2-3 seconds
- Text: Lesson title, clear and readable
- Background: Solid color or relevant image (with overlay)
- Font: Safy brand font (sans-serif, white or contrasting color)
- Animation: Simple fade-in, no overly complex transitions

**Lower Third Graphics** (if speaker appears):
- Format: Small box in lower right corner
- Content: Speaker name and title
- Font: 24pt minimum, high contrast
- Duration: While speaker is on screen
- Animation: Subtle, fade-in only

### 3.3 Text Overlay Standards

**On-Screen Text Guidelines**:
- Maximum 3 lines of text per screen
- Font size: Minimum 24pt (readable on mobile)
- Font: Sans-serif, high contrast (white on dark or dark on light)
- Duration: Text on screen 3+ seconds minimum
- Alignment: Center or lower third
- Background: Subtle translucent box (if needed for readability)

**Key Concepts Display**:
- Highlight key terms as text on screen
- Display for 3+ seconds
- Reinforce narration without duplicating word-for-word

**Text Timing**:
- Text appears just before narration mentions it
- Text remains on screen through full concept explanation
- Remove before moving to next concept

## Part 4: Post-Production Workflow

### 4.1 Color Grading Process

**Single Reference Video Color Grading** (First Video):
1. Import first video rough cut into color grading software (DaVinci Resolve recommended)
2. Create color grade using these adjustments:
   - Exposure: ±0 (neutral starting point)
   - Contrast: +5% (slight enhancement)
   - Shadows: Lifted to ~25% gray (readable)
   - Highlights: Rolled off slightly (no blown-out whites)
   - Saturation: +8% (slightly enhanced, professional look)
   - Shadows (color): Slightly warm (6000K)
   - Highlights (color): Neutral to slightly cool
   - Midtones (color): Neutral

3. Save as LUT (Look-Up Table) file: `SafyBrand_LUT.cube`
4. Export test frame for review
5. Get approval before applying to all videos

**Apply LUT to All Videos**:
- Batch apply LUT to all 18 videos
- Spot-check 3-5 videos for consistency
- Make minor adjustments per video if needed (different lighting conditions)
- Final verification on multiple devices

### 4.2 Audio Mixing

**Audio Levels**:
- Narration: -6dB to -3dB (comfortable listening level)
- Background music: -15dB to -12dB (very subtle)
- Sound effects: -12dB to -9dB (for emphasis, not distraction)
- Headroom: -3dB to -1dB (prevents digital distortion)

**Audio Mixing Workflow**:
1. Import voiceover audio
2. Normalize to -3dB
3. Add background music (if using)
4. Adjust music to -15dB below narration
5. Add sound effects (transition sounds, emphasis)
6. Mix all tracks to balanced levels
7. Export audio mix at -1dB headroom
8. Test on speaker system and headphones

**Audio Export**:
- Master mix: 48kHz, 24-bit WAV (for archival)
- Video mix: 48kHz, 16-bit AAC in MP4 (for distribution)

### 4.3 Subtitle Workflow

**Subtitle Creation**:
1. Export voiceover transcript from recording
2. Use auto-captioning tool (Rev.com, or manual transcription)
3. Manually review and correct:
   - All words spelled correctly
   - Proper capitalization and punctuation
   - Accurate timing (within 100ms of audio)
4. Break lines at natural sentence boundaries
5. Maximum 42 characters per line, 2 lines maximum
6. Export as SRT file

**Subtitle Timing**:
- Timing tool: Subtitle Edit or manual timing in Premiere
- Sync subtitle to audio
- Each subtitle timed to match narration segment
- Ensure no overlap between subtitles (except 1-frame grace)

**Subtitle Review**:
- Content Lead reviews for:
  - Accuracy (matches narration)
  - Completeness (all spoken words captured)
  - Formatting (proper line breaks)
  - Timing accuracy

## Part 5: Quality Standards & Troubleshooting

### 5.1 Quality Benchmarks

| Quality Aspect | Target | Measurement |
|---|---|---|
| Audio Clarity | Excellent | No hum, noise, or distortion |
| Audio Levels | -3dB to -6dB | Professional listening level |
| Video Sharpness | 1920x1080 | No pixelation or artifacts |
| Color Accuracy | Safy Brand | Consistent across all videos |
| Subtitle Sync | ±100ms | Matches audio within 100ms |
| Video Duration | Target ±2sec | Length matches script estimate |
| File Size | <300MB per video | Reasonable streaming size |
| Playback | Smooth 24fps | No stuttering or buffering |

### 5.2 Common Issues & Solutions

| Issue | Cause | Solution |
|---|---|---|
| Audio hum | Electrical interference | Re-record in quieter space, use balanced cables |
| Audio distortion | Levels too hot | Reduce gain during recording, normalize to -6dB max |
| Video artifacts | Bitrate too low | Increase export bitrate to 5000+ kbps |
| Color inconsistency | Different lighting | Apply LUT consistently, adjust per scene if needed |
| Subtitle lag | Timing issue | Re-sync subtitles, verify timing within 100ms |
| Slow playback | Codec issue | Use H.264, ensure bitrate appropriate for device |
| File corruption | Export failure | Re-export from master, verify file completeness |

### 5.3 Backup & Disaster Recovery

**Backup Requirements**:
- All raw footage backed up to 2 separate drives immediately after recording
- All project files backed up daily during production
- Final videos backed up to 2 separate locations
- Master files backed up to encrypted external drive + cloud storage

**Disaster Recovery Protocol**:
If video is lost/corrupted:
1. Check backup drives immediately
2. Recover from backup if available
3. If backup failed: Re-edit from raw footage (1-2 hours per video)
4. If raw footage lost: Re-record and re-edit (4-6 hours per video)

**Contingency Timeline**:
- Single video loss: 2 days delay maximum
- Multiple videos lost: Up to 1 week delay (escalate to Project Manager)
