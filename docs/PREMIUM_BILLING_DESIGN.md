# プレミアム(オリジナルコンテンツ)課金の設計

状態: 設計案(未実装)。基本契約(1人月300円・請求書払い)は `STRIPE_SETUP.md` のとおり稼働済み。

## いまの状態

- 機能: AIがテーマからレッスン・クイズを生成する(`generateOriginalContent`)。管理者画面に「オリジナルコンテンツ管理(プレミアム)」がある。
- 段階: `premiumTier` = `none` / `moduleExtension`(既存モジュールに追加・月15,000円) / `moduleCreation`(新規モジュール作成も可・月30,000円)。会社単位の固定料金(人数割なし)。
- サーバー側の制御は済み: `generateOriginalContent` は契約ドキュメント(`companies/{id}/subscriptions/company_{id}`)の `premiumTier` と有効期限を確認する。契約ドキュメントはクライアントから書けない(rules)。
- 未実装: 申し込み(決済)。画面は「準備中です。運営までお問い合わせください」。

## 方針

1. **基本契約とは別のStripeサブスクリプション**にする(同じ顧客に2本目)。
   - 理由: 席数(人数)と無関係な固定料金で、解約・変更を基本契約と独立にできる。Billing Portal もそのまま使える。
2. **Price は2つ**作る: 既存モジュール追加(15,000円/月)・新規モジュール作成(30,000円/月)。数量は常に1。
3. **基本契約(有料)が前提**。お試し・無契約の会社は申し込めない(画面で理由を表示)。
4. 反映は**サーバー(Webhook)だけ**。`premiumTier` と期限は、クライアントから書けない。

## 実装内容

### Functions
- `createPremiumCheckoutSession({companyId, tier})`(新規・管理者のみ)
  - 条件: 基本契約が有効(`billingSource == "invoice"`)、プレミアム未契約。
  - `subscription_data.metadata = {companyId, kind: "premium", tier}`、顧客は基本契約と同じ `stripeCustomerId`。
  - 戻り先は既存の `/billing-return/`(`?checkout=success|cancel`)。
- `stripeWebhook`(変更)
  - サブスクリプションの `metadata.kind` で分岐する。`kind == "premium"` は **`premiumTier` と `premiumExpiresAt` だけ**を更新し、人数・プラン(`planType` など)には触れない。
  - **重要な修正**: 現在の基本契約の反映は `premiumTier: "none"` を書き込むため、プレミアム契約中に基本契約が更新されると、プレミアムが消える。基本契約の反映からは `premiumTier` を外す(未設定のときだけ `none`)。
  - 解約・未払い確定・期限切れで `premiumTier = none`。`past_due` は当該期間の終了日まで維持(基本契約と同じ)。
- `createBillingPortalSession` は変更なし(プレミアムも同じ顧客のポータルで解約できる)。

### アプリ
- 「オリジナルコンテンツ管理」の「準備中」を、プラン選択 → 事前説明(料金・解約・請求書の取り扱い) → チェック → 決済ページ、に置き換える(「ご契約について」と同じ流れ)。
- プランの切り替え(追加 → 作成)は、初版では「ポータルで解約 → 新しいプランで申し込み」とする。差額精算つきの切替は後続。

### rules・テスト
- rules は変更なし(契約ドキュメントは書込み禁止のまま)。
- 本番e2e: 基本契約 → プレミアム購入 → `premiumTier` 反映 → 基本契約の更新でプレミアムが残る → 解約で `none` → 基本契約のない会社は購入拒否。

## 決めたいこと(ユーザー)

1. **料金**: 15,000円 / 30,000円(月・税別・会社単位)でよいか。
2. **生成の上限**: AI生成には従量のAPI費用がかかる。月ごとの生成回数の上限(例: 追加プラン30回・作成プラン100回)を設けるか。設けない場合、費用が料金を超える使い方が可能になる。
3. **前提条件**: 基本契約を前提にする案でよいか(プレミアム単体の契約は不可)。
4. **Stripe**: Price を2つ作る(テストで作成 → 本番で作り直し)。
