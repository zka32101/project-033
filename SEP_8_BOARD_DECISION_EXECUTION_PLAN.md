## Contingency Triggers

### If Approval is REJECTED
(Probability: <5%)

**Immediate Actions**:
```
[ ] CEO calls board chair to understand decision
[ ] Assess: Final decision or conditional approval?
[ ] If conditional: Work on conditions (typically financial)
[ ] If final: Board re-vote timing (typical: 30-90 days)
[ ] Internal: Message to team "We're still moving forward" (alternative funding)
```

**Message to Team**:
"The board wants to see X before approving. We have a clear path. Expect approval by [DATE]."

### If Sep 8 All-Hands Morale is LOW
(Probability: <10%)

**Immediate Actions**:
```
[ ] Skip Sep 9 kickoff, do morale check instead
[ ] CEO 1-on-1s with team leads
[ ] Identify core concerns (money? timeline? capability?)
[ ] Address concerns transparently
[ ] Re-energize with "Why we're doing this" conversation
```

**Recovery Timeline**: 48-72 hours (push Sep 9 execution back if needed)

### If Finance First Payment FAILS to Authorize
(Probability: <2%)

**Immediate Actions**:
```
[ ] CFO: Check transfer authorization status
[ ] Finance: Verify account details, banking issues
[ ] CEO: Call board finance chair if system error
[ ] Interim: Operate on existing cash until resolved
```

**Critical**: Payment must be confirmed by Sep 10 to maintain team confidence

### If Key Executive Becomes Unavailable
(Probability: <5%)

**Immediate Actions**:
```
[ ] Identify: Which role is unavailable?
[ ] Deputy: Assign backup from available leadership
[ ] Communication: Be transparent with team (illness, etc.)
[ ] Timeline: When expected to return?
[ ] Contingency: Adjust if absence >5 days
```

**Critical**: All 5 leadership roles must be staffed Sep 8-15 (GATE 2 push is critical)
